## Patch Notes
- Patch Notes is a full-stack web application that lets gamers track, review, and share their favorite games. Discover new titles, read community reviews, and keep your gaming experiences organized—all in one place!
---
### Features
- Browse Games – Discover games using the RAWG API.
- Create Reviews – Add your own thoughts and ratings for each game.
- Read & Update Reviews – View reviews from other users and edit your own.
- User Authentication – Secure login and registration with JWT.
- Responsive Design – Works smoothly on desktop and mobile.
- Game Tracking – Keep your favorite games organized in one place.
---
### Technologies Used
- Frontend: React, React Router DOM, Axios, CSS
- Backend: Node.js, Express, MongoDB, Mongoose
- Authentication: JWT (JSON Web Tokens)
- API: RAWG API for game data
- Other: CORS, RESTful API
---
### Usage
- Run Backend – Start the server to handle API requests and database interactions.
- Run Frontend – Start the React app to interact with games and reviews.
- Browse Games – Search for games or browse the library.
- Create Reviews – Log in and add your own reviews.
- Manage Reviews – Edit or delete your reviews as needed.
---
### API Endpoints
- api/users – Register, log in, and manage users
- api/games – Browse or manage games
- api/reviews – Create, read, update, and delete reviews
